# Changelog

## Unreleased — PointCloud Workflows

- Link the public pcw-go local runner, CPU example, and compatibility policy;
  keep its experimental API and untagged module status explicit.
- Add opt-in JSON protocol version 1 with uniform success/error envelopes and
  stable error categories, preserving existing `--json` and artifact formats.
- Add read-only `run inspect` for saved run metadata and verified completion,
  without loading the ML runtime or changing run files.
- Use PointCloud Core for array validation, label mapping, voxel grouping, and
  original-row lifting through a compatibility adapter. Preserve PCW error
  behavior, feature reduction, artifact schemas, and resume requirements.
- Pin Core's prepared 0.1.0 source revision and archive hash until PyPI
  publication; block PCW package publication while a direct source dependency remains.
- Add compatibility tests and an independent NumPy/Core example with sparse
  point IDs, ignored labels, and invalid coordinate/feature rows.
- Make PCW and PointCloud Core source repositories public with protected main
  branches, private vulnerability reporting, secret scanning, and push protection.
- Document PointCloud Core 0.1.0 release preparation; keep PCW at 0.2.0.dev0 and
  package/site publication separate.

- Start a fresh project history without research code, old branches, logs, or
  historical commit metadata; preserve the MIT license and approved pictures.
- Upgrade the default CPU ML runtime to PyTorch 2.13.0. Keep the GPU binary
  profile separate and document its remaining advisory and ABI requirements.
- Fetch compatibility reference source externally and test genuine 2.10 model
  inference under 2.13, while preserving strict training-resume checks.
- Prepare manual PyPI and GitHub Pages publication workflows and public controls.
- Rename the distribution to `pointcloud-workflows`, Python package to
  `pointcloud_workflows`, and CLI to `pcw`.
- Retain `rptu` and `rptu_ai_toolkit` compatibility aliases and all existing
  dataset, model, checkpoint, and run formats. The version remains `0.2.0.dev0`
  during release preparation; exact resume runtime checks apply.
- Add cross-version checks against artifacts generated by the pre-rename source.
- Update source documentation, container commands, package discovery, and CI.
- Replace the unused research dependency snapshot with the supported base
  package install and remove obsolete helper tests/dependencies.
- Add contribution, security, ownership, migration, and public-readiness guidance;
  exclude research logs and old commit metadata from the new repository.

See [migration](docs/migration.md) for installation and compatibility details.
